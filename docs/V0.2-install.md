# V0.2 : mise en service

Importer manuellement une annonce, l'analyser avec l'IA, saisir des comparables, estimer la revente et calculer la rentabilité.

## À faire dans Supabase (avant ou juste après la fusion)
1. **SQL Editor** : exécuter `supabase/migrations/0002_v02.sql` (ajout additif, sans effet sur la V0.1).
2. **Edge Functions → Deploy a new function → Via Editor** : nom `analyze-listing`, coller le contenu de
   `supabase/functions/analyze-listing/index.ts`, déployer.
   Si l'appel renvoie « Invalid JWT », désactiver l'option « Verify JWT » de cette fonction (elle vérifie elle-même l'utilisateur).
3. **Edge Functions → Secrets** : ajouter `ANTHROPIC_API_KEY` (clé créée sur console.anthropic.com, facturation à l'usage ;
   fixer une limite de dépenses). Optionnel : `AI_MODEL` pour changer de modèle (défaut `claude-sonnet-5-5`).
   Cette clé ne va jamais dans GitHub ni dans le frontend.

## Dans l'application
- **Paramètres** : renseigner les frais de vente par plateforme (0 par défaut).
- **Recherche** : « Ajouter une annonce » (saisie manuelle, aucun accès automatique aux plateformes).
- Fiche annonce : analyse IA (photos facultatives), comparables (3 minimum), estimation, calculateur.

## Limites connues de la V0.2
- Pas de recherche automatique, de filtres ni de recherches enregistrées (V0.3).
- Pas de message de négociation ni de scoring (V0.3).
- Photos analysées mais non conservées.
- Estimation sans comparables : « Estimation insuffisamment documentée ».
