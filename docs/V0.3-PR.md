   - `path="notifications"` → `<Notifications />`
4. Ajouter `src/core/opportunity-score.test.ts` aux tests (le script Node actuel `src/core/*.test.ts` doit le prendre automatiquement).
5. Exécuter la migration `0003_v03.sql` dans Supabase SQL Editor après les migrations précédentes.
6. Vérifier que `0001_init.sql` et `0002_v02.sql` sont bien appliquées avant `0003_v03.sql`.

## Limites connues de cette livraison
- Les recherches sauvegardées et les filtres avancés ne sont pas encore intégrés à l'interface Recherche. La table `search_configs` est préparée et indexée, mais aucune page de gestion n'est livrée dans ce patch.
- La génération de notifications automatiques à partir des opportunités n'est pas activée. La page permet de consulter les notifications existantes.
- Pas d'intégration Telegram.
- Le score et le bénéfice estimé déduisent les frais de plateforme configurés, mais pas les coûts non renseignés (transport, réparation, emballage). Les frais réglés à zéro sont traités comme zéro : vérifie les paramètres avant de te fier aux montants.
- Les prix affichés ne sont pas des ventes réalisées. Le score exige au moins trois comparables, une analyse IA suffisamment documentée et une confiance connue pour être éligible. Le score est plafonné à 49 sinon.
- L'actualisation qualifie les 100 annonces actives les plus récentes ; ce n'est pas une surveillance automatique de Vinted ou Leboncoin.
