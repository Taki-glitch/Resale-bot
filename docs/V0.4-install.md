# V0.4 : mise en service

Prérequis : V0.3 consolidée en place (migrations 0001 à 0004 exécutées).

## Supabase
1. **SQL Editor** : exécuter `supabase/migrations/0005_v04.sql` (ajoute colonnes, fonctions `record_purchase` / `record_sale`, vue des ventes et compartiment photo).
2. **Storage** : vérifier que le compartiment `photos` existe, est **privé**, avec des politiques `photos_*_own`.
3. Aucun nouveau secret. La fonction `analyze-listing` ne change pas.

## Vérifications rapides (SQL Editor)
```sql
select proname from pg_proc where proname in ('record_purchase', 'record_sale');           -- 2 lignes
select id, public from storage.buckets where id = 'photos';                                 -- public = false
select policyname from pg_policies where schemaname = 'storage' and policyname like 'photos_%';  -- 4 lignes
```

## Dans l'application
1. Ouvre une annonce, utilise « J'ai acheté cet article » : l'article apparaît dans **Inventaire**.
2. Ajoute des photos, des dépenses, prépare la revente, puis enregistre la vente : le bénéfice réalisé apparaît dans **Ventes**.
3. Teste les exports et la sauvegarde JSON.
