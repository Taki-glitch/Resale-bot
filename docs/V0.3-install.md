# V0.3 consolidée : mise en service

Évaluation explicable des annonces, page Opportunités, notifications dans l'application, modification d'annonce.

## Dans Supabase (avant de fusionner la pull request)
1. **SQL Editor** : exécuter `supabase/migrations/0003_v03.sql` puis `supabase/migrations/0004_hardening.sql` (ajouts uniquement ; aucune donnée supprimée).
2. Redéployer la fonction `analyze-listing` (délai maximal, erreurs explicites). Secrets : `ANTHROPIC_API_KEY` (obligatoire), `AI_MODEL` (facultatif).

## Dans l'application
- **Paramètres** : vérifier bénéfice minimum, rendement minimum, budget maximal par article, frais de la plateforme de revente et pondération du score.
- Ouvrir une annonce : ajouter au moins 3 comparables (ventes réalisées de préférence) pour obtenir une évaluation.

## Limites connues
- L'évaluation repose sur VOS comparables : sans eux, « Non évaluable ». Rien n'est inventé.
- La logistique et le délai de revente ne sont pas mesurés ; le score ne peut pas atteindre 100.
- Pas de recherches enregistrées, de Telegram, de photos stockées ni de récupération automatique d'annonces (V0.3.1).
